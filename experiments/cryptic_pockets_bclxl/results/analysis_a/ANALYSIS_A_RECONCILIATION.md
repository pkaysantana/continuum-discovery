# Analysis A: Methodological Reconciliation

## 1. What was reproduced

- **Rank-2 localization/overlap behaviour**: The `surface-fusion` detector using the `learned-fused` ranker scored the cryptic pocket at Rank 2.
- **Jaccard comparison**: The reproduction produced a Jaccard overlap of **0.366** (rounding to 0.37), perfectly validating the published claim of "Jaccard 0.36".
- **Centroid comparison**: The reproduction produced a centroid distance of **5.34 Å**, slightly tighter than the published claim of 5.6 Å.

## 2. What was not reproduced exactly

- **Raw input identity**: The reproduction was run on the aligned, stripped structural core `data/processed/apo_matched_core.pdb` generated by the repository's data acquisition pipeline, rather than the raw `1LXL` directly fetched from the PDB.
- **Undocumented upstream settings**: Lacuna's CLI default seed logic leaves NMA generation stochastic when invoked normally. The exact random seed for the original 5.6 Å run is unknown or was not fixed.
- **Exact geometry/result**: Due to differing ensembles, the 5.34 Å centroid distance vs 5.6 Å represents a non-identical geometrical output.

## 3. Preregistered conclusion

Under our preregistered **PRIMARY endpoint (centroid ≤ 4.0 Å)**:
The site is formally recovered at **Rank 10** (centroid = 3.33 Å). Rank 2 failed this strict primary cutoff (5.34 Å > 4.0 Å).

## 4. Upstream-compatible conclusion

Under Lacuna's upstream headline size-robust criterion (**Jaccard ≥ 0.25 OR centroid ≤ 4.0 Å**):
The site is formally recovered at **Rank 2** (Jaccard = 0.366 ≥ 0.25).

## 5. NMA Execution Determinism

Inspection of the Lacuna 1.2.0 `NMABackend` implementation reveals that the normal NMA path (for structures with ≥6 Cα atoms) is **deterministic**. The generator explicitly passes a fixed per-conformer seed (`seed=i`) to `_sample_ca()`, whereas the class-level stochastic RNG is only used as a fallback for small structures (<6 Cα).

Because conformer generation is deterministic for a fixed input and configuration, the difference between our obtained 5.34 Å centroid distance and the published 5.6 Å cannot be explained by stochastic NMA variance. Plausible defensible causes for this difference include:
- Use of the processed `apo_matched_core.pdb` instead of the raw `1LXL` structure.
- Variations in the exact reference-site definition boundaries.
- Variations in evaluator implementations or geometry logic.
- Differences in package versions, dependencies, or configuration between this local benchmark and the upstream environment.

## 6. Reproduction Classification

This execution should be classified as a **pipeline-validation reproduction** rather than an "exact reproduction". It validates that the pipeline functions and that the algorithmic conclusions (e.g., surface-fusion recovers the pocket at Rank 2 with excellent overlap) hold true on our harmonized input structure, but it uses a modified pipeline structure (`matched_core` subset) rather than the standalone upstream workflow.
